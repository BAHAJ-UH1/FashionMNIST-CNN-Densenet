\# FashionMNIST CNN DenseNet



This project uses a CNN + DenseNet architecture for image classification on the FashionMNIST dataset.



\## Features

\- Image classification using deep learning

\- FashionMNIST dataset

\- CNN and DenseNet model

\- Training and evaluation metrics



\## Requirements

\- Python 3.x

\- TensorFlow / PyTorch

\- NumPy

\- Matplotlib



\## How to Run



```bash

pip install -r requirements.txt

python train.py
